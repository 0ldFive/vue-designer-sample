# 多语言路由参数与语言门禁 · 设计

**目标**：示例项目语言 code 与内核 `setLanguage` 完全一致（`zh` / `zh-Hant` / `en` / `ja` / `ko` / `de`），语言由 URL query `?lang=` 驱动并支持浏览器语言自动匹配；Gitee 登录门禁与 Star 检测门禁（含门禁 UI）仅在简体中文（`zh`）下生效，其余 5 种语言直接放行。

**方案**：统一语言 code 为内核 6 code 并补齐 4 套翻译；`App.vue` 以 URL query 为最高优先级驱动 locale 并双向同步；未选择过语言时按 `navigator.language` 自动匹配；门禁放行条件为 `locale === 'zh'` 才执行登录 + Star 双重校验。

**全局约束**：
- 语言 code 必须与内核 `setLanguage(lang: "zh" | "zh-Hant" | "en" | "ja" | "ko" | "de")` 一致，项目内不再出现 `zh-cn`
- 路由参数采用 query 形式 `?lang=`（hash 路由下 URL 形如 `#/designer?lang=ja`），不做路径前缀
- 优先级：URL query `lang` > mock settings（用户显式选择过）> 浏览器语言自动匹配 > 默认 `zh`；非法 lang 值忽略回退
- 浏览器语言映射规则：`zh`/`zh-Hans`/`zh-CN`/`zh-SG`/`zh-MY`→`zh`，`zh-Hant`/`zh-TW`/`zh-HK`/`zh-MO`→`zh-Hant`，`ja*`→`ja`，`ko*`→`ko`，`de*`→`de`，`en*`→`en`，不匹配回退 `zh`；mock settings 初始 locale 为 `null` 表示"用户未选择过"
- 非 `zh` 语言下不查 token、不调 `/star-access`、不渲染门禁 UI；切回 `zh` 且未授权时从头走"登录 → Star 检测"流程
- 门禁 UI 仅在 `zh` 下出现，文案保持中文，不做多语言

## 现状与问题

- 内核（`vue-print-designer@1.8.14`）支持 6 种语言，示例项目 i18n 只有 `zh-cn` / `en` 两种，且 code 与内核不一致（`zh-cn` vs `zh`）
- `PrintDesigner.vue` / `BusinessForm.vue` 中存在 `locale === 'zh-cn' ? 'zh' : 'en'` 的降级映射，语言传参损失
- 门禁（登录 token 校验 + `/star-access` Star 检测）在 `App.vue` 中无条件执行，所有语言都被拦截
- 语言不随 URL 持久化，分享链接无法携带语言状态；首次访问不感知浏览器语言环境
- hash 路由首次导航异步解析，`onMounted` 直接读 `route.query` 存在时序坑（需 `router.isReady()`）

## 方案与取舍

- **Query 参数 `?lang=`（采用）**：改动面最小，不破坏现有菜单 `index`、页签系统基于路径的匹配逻辑；切换语言只更新 query 不跳页
- **路径前缀 `/zh/designer`（否决）**：URL 更语义化，但需重写全部路由为嵌套结构，菜单 index、页签系统、门禁跳转都要跟着改，改动面大
- **语言 code 保持 `zh-cn` 仅内部映射（否决）**：与"code 一致"需求直接冲突，且映射层会持续损耗语言传参
- **6 套语言包拆分独立文件（否决）**：现有 i18n.js 为单文件结构，保持原结构改动更集中，翻译体量可控
- **浏览器语言优先于用户已保存选择（否决）**：用户显式切换过语言应永远尊重其选择，自动检测仅在"未选择过"（settings.locale 为 `null`）时生效

## 文件结构

- 修改：`src/i18n.js`（`zh-cn`→`zh`，新增 `zh-Hant` / `ja` / `ko` / `de` 全量词条，导出 `SUPPORTED_LOCALES` / `DEFAULT_LOCALE` / `detectBrowserLocale()`）
- 修改：`src/App.vue`（elementLocale 6 语言映射、`router.isReady()` 后按优先级取 locale、URL 读写双向同步、门禁仅 `zh` 生效、语言选择器 6 项）
- 修改：`src/views/PrintDesigner.vue`（`setLanguage` 直接透传 locale，删除降级映射）
- 修改：`src/views/BusinessForm.vue`（同上）
- 修改：`mock/print.js`（默认 locale `'zh-cn'` → `null` 表示未选择）
- 测试：无测试框架，验证以 `npm run build` + dev 手动验证为准
